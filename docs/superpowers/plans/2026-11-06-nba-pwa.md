# NBA PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 自分用のスマホ向けNBA PWA（推しチーム・試合・順位・スタッツの4タブ）を作り、GitHub Pagesで公開する。

**Architecture:** ESPN非公開APIをブラウザから直接呼ぶ。`src/api/` がESPNの返却データをアプリ内の型に変換し、`src/hooks/` がTanStack Queryで取得・キャッシュ・自動更新し、`src/screens/` が表示する。ESPNの形を知っているのは `src/api/` だけ。

**Tech Stack:** React 18, TypeScript, Vite, vite-plugin-pwa, TanStack Query v5, React Router v6 (HashRouter), Vitest + Testing Library, Playwright

**Spec:** `docs/superpowers/specs/2026-11-06-nba-pwa-design.md`

## Global Constraints

- UIの文言はすべて日本語。時刻表示は `Asia/Tokyo`
- 推しチームの初期値は `min`。localStorage キーは `nba.favoriteTeam`
- Vite `base` は `/nba/`。ルーティングは HashRouter
- ESPNホスト: `site.api.espn.com`, `site.web.api.espn.com`, `a.espncdn.com` のみ
- 欠けた数値・文字列は `null`、画面では `—`（全角ダッシュ U+2014）で表示する
- 自動更新間隔: 試合中 30秒 / 試合中でないスコアボード 5分 / 順位・日程・選手成績・チーム成績 30分 / チーム一覧・ロスター 24時間
- 画面幅 390px（iPhone相当）で横スクロールが出ないこと
- 依存は上記Tech Stack + `@testing-library/react`, `@testing-library/jest-dom`, `jsdom` まで。CSSは素のCSS（CSS Modulesなし、UIライブラリなし）

## Review Focus

1. **試合のない日・オフシーズン**: `events: []` のスコアボード／空の日程で「この日の試合はありません」「予定されている試合はありません」と表示され、落ちない → Task 3, 7, 10 にテスト
2. **試合開始前・試合中のスコア**: 開始前は `score` が `"0"` や欠落、`linescores` が無い。開始前はスコアではなく日本時間の開始時刻を表示する → Task 3, 7 にテスト
3. **日本時間の日付またぎ**: 米国日付 11/5 の 20:00 ET 開始の試合は日本時間 11/6 に表示される → Task 2, 3 にテスト
4. **今季成績がない選手**（新人の開幕前、長期欠場）: overview の splits に `Regular Season` が無い → 全項目 `null`、画面は「今季の出場記録はありません」 → Task 5, 9 にテスト
5. **localStorage が使えない**（プライベートブラウズ等で例外）: 読み書きで落ちず、初期値 `min` で動く。保存値が30チームに無い略称でも `min` に戻す → Task 2 にテスト

## Shared Types（`src/api/types.ts`、Task 3 で作成）

```ts

```

ESPNの形について確認済みの事実（2026-11-06 時点）:
- scoreboard: `events[].competitions[0].competitors[]` に `homeAway`, `winner`, `score`（文字列）, `linescores[].value`, `records[0].summary`, `team.{id,abbreviation,displayName,shortDisplayName,logo}`。状態は `events[].status.type.{state,shortDetail}`
- schedule: 同じ形だが `score` は `{value, displayValue}` オブジェクト
- standings: `children[]`（`name` が "Eastern Conference"/"Western Conference"）→ `standings.entries[]` → `team`, `stats[]{name, displayValue}`。使う name: `playoffSeed`, `wins`, `losses`, `winPercent`, `gamesBehind`, `streak`
- summary: `header.competitions[0]` が scoreboard の competition と同形、`boxscore.players[]` → `team.abbreviation`, `statistics[0].{labels|names, athletes[]{athlete.{id,displayName}, starter, didNotPlay, stats[]}}`
- teams: `sports[0].leagues[0].teams[].team.{id,abbreviation,displayName,shortDisplayName,logos[0].href}`
- roster: `athletes[]{id, displayName, position.abbreviation, jersey, headshot.href}`
- team statistics: `results.stats.categories[]{name, stats[]{name, displayValue}}`。`general`/`offensive`/`defensive`
- search: `items[]{id, displayName, type:'player'}`（チーム名は `teamRelationships[0].core.displayName` にある場合あり）
- athlete overview: `statistics.names[]` と `statistics.splits[]{displayName, stats[]}`。今季は `displayName === 'Regular Season'`
